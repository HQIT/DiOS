# Linux 控制面 HA 故障资格

验证对象为三个 Linux 控制节点、标准 STONITH 设备、独占 POSIX 卷、独立 PostgreSQL 服务和一台远程 Worker。DiOS 的任务、尝试、会话、产物与 E2AG 授权使用正式 API、mTLS 网关和固定运行镜像。合成 JSONL 工作负载提供可控完成时机，不调用模型。

## 环境

使用 [主备配置](README.md)和已经通过的 Linux/共享安装流程。每个节点必须安装资源代理，并加载相同运行镜像。记录镜像配置与文件系统层；不同 Docker 镜像存储格式导入产生不同镜像 ID 时，以配置、层和实际启动的镜像关联共同核对。

基础设施准备独立实验网络、共享块设备和专用数据库。三台虚拟机同宿主时，只验证节点级机制；物理宿主、存储副本与数据库副本故障属于跨主机资格。虚拟磁盘使用 libvirt 的 `shareable` 与 `cache=none`，ext4 由 Pacemaker 独占挂载。存储复制由 Infrastructure 提供，不能对该实验盘签署复制 RPO。

Fence 凭据仅用于实验虚拟机管理，单独保管。禁止将生产实例、活跃业务数据库或恢复冻结实例接入实验。实验入口只经 VIP 放行，直接节点地址不能访问控制服务。

## 验证步骤

1. 三节点具备仲裁后应用候选配置。用 `crm_verify -L`、`crm_mon --output-as=xml --inactive` 核验资源组仅在一个节点运行；卷、服务、VIP 的启动顺序一致。
2. 通过任务 API 提交一项 E2AG 受控合成任务，由独立远程 Worker 执行并等待完成信号。记录 Run、Attempt、Session、Worker、容器 PID、process instance、授权引用及 lease epoch。另提交一项任务，在执行前通过正式撤权接口撤权。
3. 对当前主节点执行 hypervisor `suspend`。由 Pacemaker 发起真实 `off` 隔离，禁止用直接启动备用服务代替接管。记录宿主 `domstate=shut off`、原生隔离完成事件及其后的卷和服务启动事件。
4. 经 VIP 读取原任务。观测过期期间并发应为未知，不能显示为已确认运行；新鲜观测恢复后核验原进程和会话。放行合成任务完成信号，要求任务成功、产物引用完整、E2AG 结果接受有依据且 Grant 正常关闭。重复提交相同幂等键应返回原 Run；已撤权任务不能产生 Attempt。
5. 启动旧主，先确认卷未挂载、控制服务未自行启动、旧容器未自行恢复。恢复入口规则后加入集群；资源仍在当前主节点，单写者成立。
6. 暂停两个投票节点。剩余节点必须丢失仲裁，按 VIP、服务、卷顺序停止；API 不可用且卷已卸载。恢复两个节点后，确认仅一组资源启动，任务身份、撤权状态和产物 SHA-256 均保持。
7. 阻断实验节点到隔离设备的管理通道，再暂停当前主节点。确认原生隔离失败，备用节点没有启动服务或挂载卷。待即时重试耗尽和隔离设备失败记录形成后恢复通道，保持集群配置不变，不清理失败、不重启服务、不手动隔离。观察失败记录过期后的原生重试；只有真实隔离成功后才能接管。
8. 保存各阶段状态、原生事件时间、运行版本、任务与产物核验结果。确认无活跃任务后停止实验资源，再关闭实验节点和专用数据库；保留磁盘与受保护配置以便续测。

## 通过条件

| 场景 | 判定 |
|---|---|
| 旧主失联 | 旧主真实断电早于备用卷挂载和服务启动 |
| 持续任务 | 原身份与可验证执行证据关联一致，无重复 Attempt；最终结果通过原有校验 |
| E2AG | 已撤权任务无执行，结果接受与实际 Attempt/Session/epoch 绑定，完成后 Grant 关闭 |
| 观测中断 | 无新鲜证据时并发为未知，恢复后回到实际值 |
| 旧主返回 | 不自行启动旧容器，不与当前节点同时挂载卷 |
| 无仲裁 | 服务退出、VIP 撤下、卷卸载；多数恢复后单活恢复 |
| 隔离设备故障 | 无隔离成功回执时禁止接管；恢复后通过原生过期/重试机制接管 |
| 数据 | 幂等提交返回原 Run，历史及全部所查产物摘要不变 |

单次观测时间是本次故障的恢复上界，不能推导吞吐容量或全年可用性。D01-3.01 继续覆盖服务停止失败、数据库中断和完整隔离契约；D01-3.02/.03 承接物理跨主机、数据库/卷复制与 RPO/RTO 联合资格。

## 标准依据

[ClusterLabs Fencing](https://clusterlabs.org/projects/pacemaker/doc/3.0/Clusters_from_Scratch/html/fencing.html)要求确认失联节点已被隔离后再使用其资源。[libvirt 磁盘配置](https://libvirt.org/formatdomain.html#hard-drives-floppy-disks-cdroms)定义共享磁盘标记与缓存模式；[libvirt 网络配置](https://libvirt.org/formatnetwork.html)定义实验网络。节点隔离和存储实现属于 Infrastructure，DiOS 继续使用业务无关执行与授权接口。
