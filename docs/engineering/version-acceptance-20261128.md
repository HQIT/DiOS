## 版本与证据

原四条 Docker、三条采集器和六条 Harness 条款共 13 条，均有可定位的证据。完整条款、报告摘要与当前源码对应关系见[机器可读清单](../design/evidence/version-acceptance-20261128.json)。

- Docker 生命周期证据中的九个源码文件，八个保持一致。`docker_adapter.py` 后续增加 `use_config_proxy=False`，阻止宿主 Docker 默认代理绕过授权启动配置；后续 DSH 原生控制及独立 Worker 证据覆盖该改动。
- 采集器资格报告记录的 `base_commit` 是改动前基线；实际交付提交为 `1a91030`。从该提交到候选版本，17 个采集器及轮询服务文件未变。复用 25/25 专项结果、真实本地 TLS/IMAP、进程锁和镜像检查。
- Harness 后续共享代码的七处版本差异分别关联到恢复、子任务容量、结构化错误、任务查询和事务治理证据；六条真实参考路径沿用已保留产物。每份报告只覆盖其注明的场景。真实模型记录保留原固定版本，不将源码摘要相同扩展为重新执行全矩阵。

Cursor 原生控制/恢复组合为 CLI `2026.11.05-86047df`、DiOS SDK `0.1.11`、ACP SDK `1.0.0`；DSH 原生控制组合为 `0.2.2-rc.5`、DiOS SDK `0.1.19`。后续 DSH 结构化故障适配与六条参考路径分别按对应报告的组合使用；镜像完整摘要见[Harness 评审](../design/review-harness-58.md)。
