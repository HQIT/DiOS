## 已解决的架构问题

Run 重试与业务修订的关系统一为 Run/Attempt 模型；租约过期与任务死亡分别判断；技术成功增加必要产物校验。E2AG 在实际控制点执行授权，MCP 之外的原生工具和远端能力有明确接入与准入要求。治理性能提升保留授权、撤销和持久确认语义。架构层面的职责冲突与无归属缺口已收口。
