## 代表性验收场景

专业服务：授权资料检索 → 形成方案/报价 → 人工复核 → 受控外发。验证知识权限、版本、审批和外部副作用。

岗位协作：事件触发 → 多岗位分派 → 多次执行 → 复核关闭。验证长期身份、WorkItem、幂等与恢复。

个人数字分身：个体知识与记忆 → 授权会话 → 内容分享与撤销。验证数据归属、共享范围、来源追溯和权限撤销。

持续代码静态评审：选择范围 → 冻结 SHA → 全量基线/增量 → 证据验证 → 报告。验证只读边界、真实并发、持久恢复、覆盖口径、同步新鲜度及排空切换，见 [接入评估与验收清单](../design/continuous-code-review-assessment.md)。

上述场景是开放参考验收集。新增行业以同一契约和工程门槛接入，更新需求与验收矩阵。
