# ADR 0011：DiOS 能力边界与应用独立发布

- 状态：已接受；2026-11-24 用户确认“DiOS 应该是业务无关的，只和能力有关”。
- 替代范围：ADR 0003 中的产品归属与同部署起步要求；保留执行、委托、恢复和 E2AG 语义。
- 关联：#28、#33–#40、#41–#47、#51；既有 Issue 标识及历史保留。

## 决策

DiOS 是业务无关的能力平台。L1 表示 DiOS（执行内核及通用能力服务）；L2 表示 DiOS 之外的业务管理平台；L3 表示客户业务应用。层级描述依赖关系，不把 L2/L3 纳入 DiOS 产品交付。不同业务都需要的功能仍可能属于业务域，例如组织岗位和工作验收。

DiOS 提供可组合的能力：主体认证、凭据和受控委派，资源与对象授权，能力注册、版本、发布与回滚，持久调度、执行、恢复，工具与协议接入，产物、事件、检索 Provider 契约、观测与配额。应用可直接调用所需能力；使用 L2 业务平台是可选项。

## 对象与策略所有权

| 事项 | DiOS 能力域 | 上层业务域 |
| --- | --- | --- |
| 身份 | 可信身份源接入、主体引用、服务身份、令牌验证、代理链与撤销 | 企业、部门、岗位、成员关系、数字员工职责与负责人 |
| 范围与权限 | 不透明资源引用、动作、版本、作用域、策略交集及 E2AG 实际执行门禁 | 项目、客户、课程、资料分类；谁因何业务关系可以访问什么 |
| 资料与成果 | 对象存储、版本、摘要、来源引用、读取/下载授权、留存机制 | 业务归属、目录分类、保密等级规则、成果复核及发布条件 |
| 工作与审批 | Run/Attempt/Session、技术状态、ApprovalRequest、决议绑定与恢复 | WorkItem、任务分派、审批人选择、提醒升级、业务完成和验收 |
| 知识 | 可替换 Provider、受控检索、引用、版本与更新/删除传播契约 | 项目数据库、行业知识组织、配方及产品字段、客户源系统 ACL |
| 管理界面 | Console、凭据/策略/能力配置、运行及资源观测 | 员工/主管工作台、客户门户、业务指标和成本分摊 |

业务系统产生授权依据；可信策略适配器将其映射为 DiOS 可校验的约束。DiOS 验证签发者、受托关系、资源与有效期，在实际动作处执行。应用提交的 project_id、role 等普通输入不构成权限证明。资源类型扩展通过契约登记，不在底座增加项目或岗位分支判断。

## 独立部署与数据边界

DiOS、L2 业务平台、客户应用分别拥有构建物、配置、凭据、版本和升级流程。可以共用主机或数据库实例，但业务表与运行表各有所有者，禁止跨产品写表或共享 ORM 实体。上层使用版本化 API/事件/协议；受管工作负载以独立镜像和固定摘要登记。业务输入与执行证据通过稳定引用关联。

应用发布不要求重编 DiOS；DiOS 发布不要求迁移业务表。应用停用应停止新任务准入并保留历史；运行中升级遵循排空与所有权对账。旧包和契约兼容窗口共同支持回滚。单节点用于开发验证，跨主机与两档容量路线保留。

## 当前实现与分步交付

2026-11-24 的改动解除任务入口对参考应用模块的导入及新任务类型白名单。管理员登记任务类型、输入目录、JSON Schema 和摘要策略；DiOS 校验、冻结输入并保存登记摘要，应用执行自身业务验证。E2AG 为登记输入默认要求；本地可信测试可显式关闭。历史查询以入口标识投影，保留旧任务读取兼容。

现有 apps/evidence_brief、apps/inline_review 与 services/knowledge 仍是同仓工程样例，Provider 的 project_id 归参考应用协议；当前尚未完成独立应用发布包和通用 Provider 协议的全部拆分。独立进程和容器证据不等同于完整产品独立发布。

接续 #47 的应用包/客户端契约，移出参考应用与参考 Provider 的业务实现；#33/#35/#38 先完成主体、资源对象和撤销能力。#36/#37/#40 的组织、员工与工作流程保留为上层业务交付，不作为 DiOS 发布前置。既有计划中其他通用能力继续完成，客户实现按各自计划推进。

## 验收

1. 不改 DiOS 源码即可登记第三种任务；API 不导入或运行应用验证器，JSON Schema 不访问外部 URI。
2. 未登记输入、摘要错误、Schema 不匹配和缺少要求的 E2AG 均不能入队；应用执行仍验证业务条件。
3. 登记更新或停用后，已有 Run 的输入、Attempt、Session、Artifact 和历史身份不变。
4. 两个独立构建的应用包可分别升级与回滚；上层故障不改变底座所有权；跨产品禁止直接读写私有表。
5. 资源读取、下载和工具调用使用同一受限身份链；撤销与旧凭据测试通过后接真实客户资料。

前三项由本批注册契约测试覆盖；独立发布与多主体对象权限按后续实现分别验收。
