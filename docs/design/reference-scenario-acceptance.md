# 参考场景验收集与扩展准则

任务：[F03-2 #29](https://github.com/HQIT/DiOS/issues/29) · P0 · 设计/合成样例交付，待评审。对应 [工作台原型 #28](workbench-information-architecture.md)。

## 统一验收结构

每个场景固定 Workspace、WorkItem、EmployeeBinding、Revision、Run、Attempt、Session、Artifact 与授权证据。业务结果由 L3 定义，协作/验收由 L2 管理，执行与工具边界由 L1 管理。输入见 [合成样例](fixtures/reference-scenarios.json)，工作台使用同名场景演示状态；故障脚本只能针对隔离测试执行端。

| 场景 | 输入 / 预期成果 | 验收主体与权限 | 失败与恢复 |
| --- | --- | --- | --- |
| 专业服务 | 两份规格与约束 → 有引用的选型建议 | 员工读本空间；主管确认外发；平台管理员管理能力 | 缺规格进入待补充；外发参数变化使审批失效；撤销在工具边界拒绝 |
| 岗位协作 | 三岗位计划，一项缺责任人 → 有来源的汇总 | 发起人委派既有范围；各岗位只交本岗位材料；主管验收 | 缺项向责任人请求接管；重试不重复委派；迟到结果按版本对账 |
| 教育数字分身 | 教师材料与受限答案 → 导读/学生练习版 | 教师复核；学生仅访问分享版；撤销阻断后续访问 | 无引用成果退回；跨会话延续身份；分享失效后缓存/检索也受限 |
| 持续静态评审 | 冻结分支 SHA、缺陷与修复对照 → 问题证据、覆盖账本、报告 | 管理者选范围；Worker 只读检索；复核者确认问题 | 缺证据待验证，完整产物优先抢救；断网补报，单所有者切换 |

所有组织、文件和代码均为合成材料。客户类型为参考来源，新行业不受此集合限制。

## 跨 Agent 与治理共同场景

每种业务至少在两种独立 Agent 实现运行同一输入与验收条件，登记实现版本、协议版本、能力快照、托管/远端模式。A2A、ACP、厂商接口按实际探测结果选择；缺失能力不由界面假定。

| 输入/动作 | 预期证据 | 任务 |
| --- | --- | --- |
| 端点声明 `cancel=false`，提交需要可靠取消的工作 | 准入拒绝或提示更换实现；无伪造取消成功 | #56/#58 |
| 断开连接但进程仍活跃 | 观测过期，保留会话身份；对账后恢复 | #30/#56 |
| 撤销运行中授权，再尝试读取/外发 | E2AG 实际控制点拒绝，绑定 Attempt/epoch；拒绝来源可追踪 | #34/#35/#58 |
| 相同 callback id 重放 10 次并乱序 | 一次状态推进；旧版本不覆盖；原事件可审计 | #30/#32/#56 |
| 人工接管后 Agent 迟到返回 | 接管与取消分别记录，成果进入复核，不覆盖人工决定 | #40/#58 |
| 切换实现并交接会话/成果 | WorkItem 与历史身份连续，权限不扩大，远端引用保留 | #37/#38/#58 |

## 静态评审十八项故障/一致性验收

承接 [现有评估](continuous-code-review-assessment.md)。基准输入固定为 `fixtures/reference-scenarios.json` 的 review 场景；SHA 是样例身份，隔离 harness 将所给文本物化为版本，并记录真实生成 SHA。每项结果保存输入摘要、时间、所有者 epoch、Run/Attempt/Session、进程证据、事件与产物摘要。

| 编号 | 可执行输入/注入动作（隔离环境） | 必须成立的断言 | 承接 |
| --- | --- | --- | --- |
| R01 重复触发 | 对同一 workspace/repo/branch/SHA、同幂等键并发提交 10 次；随后提交新 SHA | 1 个有效规划所有者、1 个同键 Run；新 SHA 保持待处理水位 | #30 |
| R02 真实并发 | 上限设 3，运行 3 个独立 Worker，各输出 PID、boot_id、子进程 PID、session_id | 3 组活跃证据才显示 3；停止一路后显示实测 2 或未知 | #10/#30/#58 |
| R03 断网 | 模型输出首段后断开测试代理 60 秒再恢复 | 部分输出留存；先对账；未证明结束时不重派 | #30/#56 |
| R04 子进程崩溃 | 保持 RPC 请求未完成，终止其隔离 ACP 子进程 | 有界终止等待；错误及输出留存；后续任务可推进 | #10/#30/#56 |
| R05 主机重启 | 持久任务运行中重启隔离节点 | boot_id 更新，旧租约不能续写；逐任务恢复/对账，无永久占槽 | #30/#32/#58 |
| R06 限流/额度 | 前两次响应 429 与 quota 错误，之后恢复成功 | 分类错误与下次重试可见；单路试恢复，成功恢复并发 | #30/#56 |
| R07 完整输出抢救 | 完整 JSON 产物落盘后，在状态提交前中止执行端 | 原产物校验完成同一 Run；模型调用计数不增加 | #30/#32 |
| R08 截断/缺证据 | 分别移除 JSON 末尾字节、问题的位置/可达条件字段 | 原输出保留；格式错误重解析，证据不足待验证；成功覆盖不增加 | #30/#59 |
| R09 查询超时/长等待 | 会话持续事件但无最终答案，阻断观察 API 响应 | 等待模型与观测过期分别展示；无重复派发；同步故障独立 | #30/#46 |
| R10 僵尸所有者 | epoch=1 暂停后转移至 epoch=2，再回传 epoch=1 结果 | 旧 epoch 不写新状态；迟到输出保留在隔离审计 | #30/#32 |
| R11 详情上传失败 | 拒绝大产物上传，进度事件重复且倒序投递，然后恢复 | 小进度继续、按水位去重；详情新鲜度独立；续传校验一致 | #32/#46 |
| R12 UTF-8 分块 | 按 1/2/3/7 字节切分“中文审查🙂”；中断后从已确认偏移续传 | 原始字节摘要与回读一致；压缩摘要单独记录 | #32/#59 |
| R13 运行中升级 | 3 路活跃时设 drain，同时触发新任务，再等待自然结束 | 停领新任务，活跃任务结束后切换；会话不重复、未完成工作保留 | #10/#30/#51 |
| R14 无人值守 | 隔离计划任务移除 Git PATH，再移除代理；恢复配置重跑预检 | 精确依赖错误；修复后可执行；凭据不写日志、后台无反复窗口 | #10/#51 |
| R15 只读 | 请求写源码、编译、运行包脚本、越权外发；记录执行前后源码摘要 | 实际控制点逐项拒绝；摘要不变；E2AG 证据关联 Attempt | #34/#58/#59 |
| R16 覆盖与复用 | 同 blob 分别置于相同/不同依赖上下文；新增分支；手动包含过期分支 | 相容上下文才复用审核；全范围分母保留；各分支/版本关联可复算 | #59 |
| R17 质量报表 | 缺陷/修复留出样本与同 QuerySpec、水位的 UI/Excel/Markdown | 混淆矩阵、覆盖、分阶段耗时可复算；过滤后的统计/导出一致 | #43/#59 |
| R18 回滚 | 新系统产生结果后请求交回旧控制器，分别模拟兼容/不兼容版本 | 历史身份完整；单分区仅一所有者；不兼容时保持安全排空并阻止切回 | #11/#60 |

以上是可供 harness 实现的操作与断言设计，运行结果逐项登记为 planned/passed/failed/blocked，并关联证据路径。原型状态测试不替代真实故障注入。生产评审保持原调度器与历史，迁移由 #60 单独验收。

## 新行业包模板

新增场景提交以下字段：`scenario_id`、业务目标、合成输入/摘要、预期成果与验收者、主体/资源/动作权限矩阵、所需协议能力和缺失能力行为、复用的内核/服务对象、失败/恢复断言、指标口径、数据保留与脱敏、适配器/模板/工具包依赖、证据清单。

准入步骤：复用上述共同用例 → 补充行业验收 → 至少两种实现验证 → E2AG 拒绝路径与人工复核通过 → 固定包版本及回滚路径。需要修改内核语义时提交 ADR；业务规则优先在 L3 包内表达。
