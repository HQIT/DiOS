## 责任边界

Infrastructure 提供计算、网络与隔离；DiOS 管理任务、尝试、Worker、会话关联、工作授权、审批、工具派发、恢复和产物。独立的数字分身平台组织客户无关的管理与服务，客户应用定义业务任务、报告与业务验收。静态评审合成样例用于验证 DiOS 契约，客户组织、仓库业务范围和行业流程仍由上层应用负责。

E2AG 将允许动作绑定到当前工作授权、调用参数、委派和租约。ACP 许可允许进入受控工具代理，实际动作仍由工具网关决定。DSH 执行前 guard 与 Cursor 固定权限策略收紧 Harness 原生能力；容器及出站代理提供独立文件、网络控制。

## 版本变化与证据复用

证据索引逐份列出当前源码与报告所记录摘要的差异。没有记录源码摘要的报告，只能按其中固定镜像和场景解释。

Cursor 恢复后的 Worker、Reconciler 和故障分类增加了控制面中断恢复；后续 [数据库中断](evidence/ha-recovery-20261126.json)及[保留 TCP 的数据库暂停](evidence/ha-stall-20261126.json)验证了同一工作重新对账、重新授权和产物保留。这些场景使用合成 Agent，保留其适用范围。

工具通道、应用入口和子任务服务的后续修改在索引中列明；最新 DSH 资格覆盖当前 Worker/E2AG 的正常与负面执行路径。旧报告继续证明其固定组合，最新源码的全部组合仍须由评审按变更影响判断。版本发布模块及协议恢复记录中的源码摘要可直接核对；复用不增加能力声明范围。
