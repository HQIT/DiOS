# 全局显示与语言偏好

主题支持 Light、Dark、Auto，默认 Auto，实时跟随系统深浅色。语言支持中文、English、Auto，默认按浏览器首选 Locale：zh-* 使用中文，其余使用 English。用户手动选择后保留偏好，选择 Auto 可恢复系统或浏览器默认。

设置入口覆盖登录、Console、Chat 和工作台。浏览器本地存储不可用时保持当前页可用；同源标签页同步偏好。首次绘制前应用主题，切换时保留当前路由、页面状态和表单输入。

`lib/preferences.ts` 管理偏好与订阅；`lib/i18n.ts` 和 `lib/messages.ts` 负责展示层消息；原始业务数据、用户输入、来源资料和报告保持原语言。UI 组件显式调用翻译函数，API、运行状态机和业务模型保持原协议值。

主题使用 CSS 变量；工作台保留原浅色设计，并提供深色 token。新增界面消息和语义颜色应沿用这些入口。

工程验证见 [证据](evidence/preferences-20261123.json) 与 `scripts/check_preferences.mjs`。覆盖默认值、实时主题变化、偏好记忆、跨页及跨标签更新、登录/任务/抽屉输入保持、存储不可用和移动布局。
