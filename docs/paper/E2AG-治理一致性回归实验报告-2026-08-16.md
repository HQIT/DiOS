# E2AG 自有设施治理一致性/越权回归实验报告（2026-08-16）

## 1. 实验目的与边界

本轮将 qame–demogo 验证定义为治理一致性回归，回答同一科学问题：任务已获准创建后，运行时 MCP PEP 是否始终按该任务的 ToolGrant 执行，并使集合外请求在到达上游前失败。实验使用自有 demogo DiOS、`git-perf` 与公开仓库 `HQIT/qame`。负向量的工具名和参数由固定脚本给出；后续复验也只允许确定性 harness 触发，模型不参与负对照的构造或调度。

## 2. 配对设计

正对照沿用已冻结的真实 `qame → demogo → task-mode DiAgent → ToolGrant/MCP PEP → git-perf` 轨迹：事件 `868f8eab67ca`、trace `1c65e55240994b10965b49ba4791f223` 最终完成，5 次获准工具调用抵达上游，任务终态后 grant 撤销。

负对照固化刚刚取得的事件 `81bf61a28689`、trace `67f73ca2e9654022b6ad6e9686736fd4`。该任务的 ToolGrant 仅含 `record_push`、`record_review`、`list_pushes` 和 `list_reviews`；固定回归向量请求集合外工具 `mark_effective_commit`。观测 PEP 响应、审计项、上游状态与 canary 数据是否变化。

## 3. 结果

| 检查项 | 正对照 | 固定越权负对照 |
|---|---|---|
| 真实 qame→demogo 事件 | 是 | 是 |
| ToolGrant | 签发并在终态撤销 | 签发并在终态撤销 |
| 目标工具是否在 grant 中 | 是 | 否 |
| PEP 结果 | allow，上游 HTTP 成功 | HTTP 403，`MCP_TOOL_NOT_GRANTED` |
| 审计证据 | 获准调用有上游状态 | sequence 8 为 `tool_call/deny`，`upstream_status=null` |
| 上游状态 | 产生匹配 push/review 证据 | canary 保持 `effective=0`，记录数仍为1 |
| 哈希链 | 有效 | 11 项审计链有效 |

负对照实现了三重闭合：PEP 明确拒绝；审计表明请求未取得上游响应；独立读取 `git-perf` 数据确认目标 canary 未发生状态变化。结构化证据位于 `experiments/e2ag/results/external_governance_regression_summary.json`。

## 4. 论文允许主张

该结果支持：在当前 task-mode Streamable HTTP MCP 路径和完整中介假设下，运行时 PEP 与已签发 ToolGrant 保持一致，集合外工具请求不能抵达上游。它不支持模型安全率、自然流量违规概率、参数级数据流安全或跨 AIOS 泛化结论。

本次已经取得的拒绝轨迹作为冻结证据保留。以后若复验，负向请求必须由 `external_governance_regression.py` 或等价确定性 harness 直接构造；模型不参与工具名、参数或调度选择。
