# 完整治理路径计时预试验与问题定位

2026-09-30。回应R1.3/R2.3的测量准备。本轮只使用已曝光的VS Code开发输入，不接触11个留出对象，不运行三方正式比较，不修改生产服务或论文正文。按论文修订skill区分实测路径、功能核验、性能预试验与正式结果，不将重复请求数当作独立业务规模。

## 实际完成范围

新增三进程隔离测量：闭环驱动器、单worker的DiOS原生路由应用、独立HTTP工具服务。计时涵盖事件HTTP接收、标准化、订阅匹配、准入、任务提交、能力签发、工具读写及原生审计提交。替换仅限模型/容器调度，由确定性执行器产生读写；任务仍为原生submitted，不冒充自主Agent完成态。连接信息通过每任务一次HTTP获取，无轮询，开销计入工作流延迟。

G0关闭治理但保留事件/任务基础记录；G1保留完整准入、工具直连；G2签发任务能力并经过原生HTTP代理。三配置使用同一业务计算、上游文件读写/fsync、数据库设置及客户端连接池。原生G2代理内部逐调用创建HTTP客户端的实现保持不变，因此对照测量的是当前完整集成增量，不是孤立的PDP算法时间；这个连接策略差异必须披露，不能从G2总耗时直接推导授权算法开销。

每配置单元重建数据库并重启应用/工具进程；预热之后保留该单元数据库，测量阶段因此不是每请求空库。计时使用各自进程内单调时钟；跨进程仅用request/event/task/trace及JSON-RPC id关联，不相减不同进程的时间戳。记录计划发送、实际发送、准入响应、读取、业务计算、写入和完成时刻；SQL提交、授权谓词、客户端初始化/关闭、上游转发为可关联的嵌套跨度，不能简单相加。

先完成两种开发输入×三配置、并发1、各3秒的6格资格检查。随后启动单轮预试验：两输入×三配置×并发1/8/32，共18格；每格预热2秒、测量发起窗口8秒，配置顺序由固定seed 20260930生成并在首请求前保存。这些时长只用于工具预试验，不替代候选正式方案的5轮/30秒预热/120秒测量。

预试验推进到第6格时因资源阈值停止。已启动的6格均为issue输入，测量阶段合计566次请求、566次完成、0次错误；预热152次单列，不并入测量分母。剩余12格未执行，包括全部并发32及PR并发预试验，不能把此前PR并发1资格检查充当缺失格。成功请求的事件/任务关联、原生审计链、上游读写、G2调用计数和报告正确性核查通过，三配置实际写入的报告内容哈希相同。

## 环境、停止条件与测量修正

本地Windows 11（10.0.26200），Intel Core Ultra 7 255H，系统报告16物理/逻辑核，总内存33,752,997,888字节；Python3.12.10、SQLite3.49.1、httpx0.28.1、FastAPI0.141.1、uvicorn0.52.1、SQLAlchemy2.0.52、aiosqlite0.22.1。为资源采样在现有实验虚拟环境按大陆镜像安装psutil7.0.0，未升级其他依赖。

应用使用SQLite DELETE日志、FULL同步、5000ms busy_timeout，连接池5+10 overflow，上游为独立进程内的线程式HTTP服务，工具写入和操作记录均flush/fsync后返回。测试工具只实现本实验所需的JSON-RPC tools/call，不包含MCP会话初始化或完整互操作性测试。全部监听127.0.0.1，无外部模型和远端压测。客户端HTTP超时30秒，每格保留完整日志，未通过重试遮盖失败。

全机可用内存低于15%持续10秒的停止条件生效，第6格最低观测约12.74%。此前已有约14%—16%的内存余量，不能把全部内存压力归咎于E2AG。磁盘余量约54GB，没有触发5GB磁盘阈值；未触发错误率持续阈值。停止后不扩大负载、不放宽阈值、不关闭用户其他进程。

本轮同时发现Windows虚拟环境启动器PID与真实服务PID不同：v1测量器采样了启动器，因此v1服务CPU/RSS数据无效。v2核查报告显式屏蔽这两项派生指标，原始记录完整保留；整机内存/磁盘采样和客户端时钟记录不依赖这些PID，仍可用于诊断，但整轮不能作为正式性能结果。

已修改测量器：通过本地健康检查返回实际PID，验证其属于本次创建的进程树，再采样实际服务；退出时回收整个自建进程树。另用1次G2请求验证，真实服务PID不同于启动器、RSS采样落在实际服务，原生关联与业务结果通过，退出后检查无本测量器服务残留。这1次是修复资格检查，不补记进原18格，也不说明正式资源测量已经完成。

6项测量单测通过，覆盖最近秩分位数、停止阈值持续时间/复位、失败与预热分离、排空不计入窗口完成吞吐。独立核查脚本从落盘记录重算请求数/分位数并核对时间顺序、SHA、唯一id、数据库关联、落盘报告与事件匹配。v1旧核查记录不删除，资源指标有效性以v2核查为准。

## 证据与后续

实验目录`experiments/e2ag/rr022/`中的新增入口：`performance_pretrial.py`、`test_performance_pretrial.py`、`check_performance_pretrial.py`。原始结果：

- `results/performance-timing-qualification-20260930-v1.json`：6格单并发计时资格检查，非正式成绩。
