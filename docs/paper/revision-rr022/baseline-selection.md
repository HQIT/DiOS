# rr022 外部基线选择与 OPA 对照说明

核查日期：2026-09-29。状态：已核对原论文、官方仓库、部分源代码与依赖声明；经作者确认后进入隔离环境可行性小试，不代表正式比较或整篇论文复现。论文正文及旧实验结果不变。小试结果另见 `baseline-feasibility.md`。

## 决定

按作者确认的方向，**AgentSpec 是主学术基线，Agent libOS 是紧邻系统补充对照，完整上下文 OPA 是策略引擎替换对照**。此前只优先 Agent libOS 的初选已被本决定替代。选择须兼顾学术代表性、方法先进性、保护对象相近程度、原实现可追溯性、共同场景与可复现性；不能按预期输赢或 GitHub 星数选择。

AgentSpec 的 [ICSE 2026 Research Track 官方记录](https://conf.researchr.org/details/icse-2026/icse-2026-research-track/29/AgentSpec-Customizable-Runtime-Enforcement-for-Safe-and-Reliable-LLM-Agents)确认其正式发表（DOI 10.1145/3744916.3764546）。这提供同行评审依据，但不等于所有任务上最先进或已广泛独立复现。Agent libOS 当前仅核实预印本与作者实现，不能称为公认 SOTA。先进性由具体机制与公平实验评估；广泛认可需另有独立采用/复现证据。

Agent libOS 的当前实现包含任务权限、资源能力、审批、事件与审计，和 E2AG 存在实质重合，因此应正面核查，不能为了节省成本而只挑工具名过滤方案比较。是否存在本文独有的跨层性质，需要实验和代码对应关系验证，当前不能预判。

## 什么是 OPA 对照

OPA 是 Open Policy Agent，一种通用策略判定引擎。应用提供结构化输入及策略，OPA 返回判定；调用是否真正被拦截，仍由应用的执行点负责。官方说明明确分离 policy decision 和 enforcement，并允许任意结构化输入与输出：[官方文档](https://www.openpolicyagent.org/docs)。

旧脚本 `experiments/e2ag/run_opa_tool_baseline.py` 的 `run_opa` 仅传入方法、工具名和允许工具集合。它没有来源、任务、审批、能力生命周期上下文。因此旧结果只能说明局部上下文的局限，不能证明 OPA 不能表达跨层授权。

建议增加暂名 **E2AG-with-OPA** 的替换对照（不是文献方法名称）：保留同一事件规范化、任务绑定、可信状态存储和两个执行点，把相关判定逻辑用独立 Rego 规则实现。提供实际来源身份、事件类型、目标、任务/能力标识、审批状态、有效期/撤销状态及实际参数资源；时间与状态由可信宿主提供，不能接受模型自报。只给原始事实和规范化规则，不给 E2AG 已计算的 allow/deny 结果。

用同一授权规范、同一输入、同一上游工具比较三态决策与可观察执行结果。批准状态转移、一次性消耗及竞态控制不能只靠一个布尔输入替代，继续由共享的可信事务层负责，须明确哪些代码共享。该实验回答“策略引擎能否替换而保持治理语义”，不回答“OPA 自身是否提供整套 E2AG 架构”。如果双方结果一致，应当如实报告为可组合性证据，而非寻找人为差距。

例：同一获准的报告工具，在审批尚未完成、能力已经撤销或资源不属于当前任务时，应暂缓或拒绝。给充分上下文的 OPA 完全可能作出与 E2AG 相同的决定；区别不能归因于策略引擎名称。

## 可行性试验与正式接入门槛

1. 固定 AgentSpec 和 Agent libOS 快照，在两个独立环境核对最小依赖与原生执行路径；不混用 DiOS 环境、不修改机器全局配置。大陆 pip 镜像优先，依赖声明不等于安装成功。
2. 用临时资源和固定调用做少量允许/拒绝/审批、资源范围、能力撤销及审计案例。保留其原生执行与能力机制，只作输入和结果适配；不把它挂到 E2AG 执行点后假装成独立系统。
3. 对照双方可表达的同一授权规范，明确 ask 与 approval 的语义映射、审批恢复及状态绑定；不可比较项单列，不以“不支持”直接计为安全失败，也不删除这些项的覆盖信息。
4. 记录适配改动、公共场景及不可比较项。若主学术基线需重写核心或一天内无法跑通，先报告阻塞，再讨论替代方案，不悄悄改用学术依据更弱的基线。小试中的输入构造错误或兼容性错误不得作为对方方法的安全失败。
5. 冻结正式比较协议前展示逐条轨迹。通过小试不等于正式实验完成，更不能直接套用对方论文的性能数字。

依据论文修订 skill 的“共同输入、原实现与适配分离、证据先于论述”要求完成选择与小试；不启动正文中关于外部方法不足的改写。
